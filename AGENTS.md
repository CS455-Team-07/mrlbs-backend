# Instructions for AI Coding Agents

## AI engineering log

- Record meaningful AI-assisted engineering work in [`AI_ENGINEERING_LOG.md`](AI_ENGINEERING_LOG.md). Log AI assistance that materially contributes to requirements, architecture, design, implementation, testing, debugging, documentation, or project decisions.
- Do not log trivial interactions that do not affect the project.
- For each meaningful AI-assisted task, record:
  - Date
  - Task and context
  - Prompt
  - AI output or response
  - Student/team evaluation
  - Errors, risks, or hallucinations identified
  - Changes made after evaluating the AI output
  - Final accepted artifact or output
  - Decision: Accepted, Modified, or Rejected
  - Reason for the decision
- Never fabricate prompts, AI responses, evaluations, test results, or decisions. If exact prompt or response text is unavailable, state that limitation explicitly and provide a faithful summary instead.
- Append entries chronologically. Never delete or silently rewrite a previous entry; add a new entry to document a correction or later evaluation.
- The human team member remains responsible for evaluating AI-generated work and recording that evaluation.
